# 特別価格回答 集約ツール（price-db）

各案件で作成した特別価格回答Excelを共有フォルダから自動で集め、価格分析用の「価格マスタ」を作ります。
Mac / Windows のどちらでも動きます（Python 3 と openpyxl だけで動作し、Power Query は不要です）。

> **価格データ（Excel/CSV）は Git に登録されません。** GitHub に置くのはスクリプトとテンプレートだけです。

## 構成

| ファイル | 役割 |
|---|---|
| `templates/特別価格回答テンプレート.xlsx` | 今後の回答に使うテンプレート（「データ」シート付き） |
| `集約実行.command` | **Macでダブルクリックするだけで集約を実行** |
| `collect.py` | 集約スクリプト本体 |
| `make_template.py` | テンプレートを作り直すスクリプト（列を変えたとき用） |
| `columns.py` | 列の定義（テンプレートと集約で共通） |
| `config.example.ini` | 設定の見本（コピーして `config.ini` にする） |

## Macでの初回セットアップ

1. **ターミナル**を開き、リポジトリを取得します（一度だけ）。
   ```bash
   cd ~/Documents
   git clone https://github.com/shigeru-run/my-travel-planner.git
   cd my-travel-planner
   git checkout claude/funny-archimedes-te3uye   # main に取り込まれたら不要
   ```
   `git` が無いと表示されたら、案内に従って「コマンドライン・デベロッパツール」をインストールしてください（python3 も同時に入ります）。
2. Finder で `my-travel-planner/price-db` を開き、`集約実行.command` をダブルクリックします。
   - 初回は `config.ini` が作られ、テキストエディットで開きます。
   - `input_dir` を共有フォルダのパスに書き換えて保存します（例: `~/Library/CloudStorage/OneDrive-会社名/特別価格回答`）。
   - 共有フォルダのパスは、Finder でフォルダを選び、option キーを押しながら右クリック →「"…"のパス名をコピー」で取得できます。
3. もう一度 `集約実行.command` をダブルクリックすると、`output/価格マスタ.xlsx` と `.csv` ができます。

「開発元を確認できないため開けません」と出た場合は、右クリック →「開く」を選んでください。

## 普段の使い方

- 回答を作るとき: テンプレートの「データ」シートに 1行=1品目 で入力し、共有フォルダに保存します。
  既存の回答書の様式を使う場合は、「データ」シートだけをコピーして追加してください。
- 集約するとき: `集約実行.command` をダブルクリックします。毎回フォルダ全体から作り直すので、何度実行しても重複しません。
- ツールを更新するとき: ターミナルで `cd ~/Documents/my-travel-planner && git pull` を実行します。

## 価格マスタの中身

| シート | 内容 |
|---|---|
| マスタ | 全回答の明細（テーブル `tbl_master`）。ピボットテーブルでそのまま分析できます |
| 未取込 | 「データ」シートがない旧様式ファイルや、読めなかったファイルの一覧 |
| 取込ログ | ファイルごとの取込行数 |

値引率は `1 - 特別価格 / 標準価格` で集約時に計算し直します。

## 旧様式（過去分）のファイル

「未取込」シートに載ったファイルは様式がバラバラなので、AI（Claude など）に渡して
「データ」シートの列構成に変換してもらい、変換後のファイルを共有フォルダに置けば次回から取り込まれます。

## 列を変更したいとき

`columns.py` を編集 → `python3 make_template.py` でテンプレートを作り直します。
集約スクリプトは列名で読み取るので、列の順番が違うファイルや、一部の列がないファイルも取り込めます（必須は「品番」「特別価格」）。
